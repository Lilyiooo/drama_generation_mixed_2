## 方法对照

| 项目 | all_subtree | nmf_no_cards |
|---|---|---|
| 实现来源 | 我们的_simple pipeline | drama-generation独立适配入口 |
| 记忆组织 | 未来需求树、逐集贡献映射、事件与世界状态记忆 | 累积状态、状态生命周期、开放叙事义务 |
| 历史信息选择 | 直接关联记忆全部；相关后代子树中非伏笔记忆全部，不取top10 | 累积状态和当前开放义务进入prompt，无需求树top10检索 |
| 子树伏笔 | 不纳入子树补充记忆；直接关联伏笔仍保留 | 在开放叙事义务中记录与更新 |
| 经验卡 | 无该仓库V4经验卡机制 | 已关闭检索、注入、写回与卡反模式门 |
| 单集生成 | 先场次大纲，再整集正文 | 直接根据当前集八字段大纲生成整集 |
| 字数调整 | 本次实际关闭 | 无 |
| 与上一集衔接润色 | 本次实际关闭 | 无 |
| 全部前集正文 | 不采用baseline的全部正文累积方式 | 不提供全部前集正文 |

all_subtree本次关闭两项后处理，依据实际输出的 `resume_from_episode_outline.json` 中 `adjust_word_count=false`、`adjust_coherence=false`，不是按启动脚本的默认值推测。

nmf_no_cards首集动态状态为空，背景和人物设定单独提供；每集完成后抽取状态增量及义务变化，再合并和清理已解决事项，传给下一集。当前集完整八字段大纲进入prompt，不提供后续集大纲。通常每集一次生成、一次抽取，格式失败另有重试。
