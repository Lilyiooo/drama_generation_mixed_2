# 第二版评测 Prompt：`given_setting_dedup`

此目录归档 PG19 V1 与直接生成 baseline 三轮对比中使用的**首版去重口径**，即此前所称的评测 pipeline v2。它不同于后来命名为 `given_setting_dedup_v2` 的改良去重口径；本目录不包含后者。

## 与仓库内 v24 的差异

以 `evaluation/drama_evaluator_logic_quality/prompts/` 中的 v24 标准为基础，保持逻辑和质量的其余原始细则、S/A/B 锚点、五个质量模块及 50/50 融合公式不变，仅按以下顺序组装：

1. 逻辑：原 `剧本逻辑.md` 后追加本目录的 `剧本逻辑_去重边界.md`。
2. 质量：沿用原 `人物质量.md`、`卡点质量.md`、`情节规划质量.md`、`分集剧本质量.md`；将原 `设定质量.md` 替换为本目录的 `剧本质量/设定落地质量_给定设定.md`；最后追加本目录的 `剧本质量/去重评测边界_给定设定.md`。

三个新增文件与实际评测使用的 Prompt 文件逐字一致。已完成结果的标准哈希为：逻辑 `cbd5906476500544fba9bf80eb321d12d852d0b03b28cff6156ecac6c261c1a0`，质量 `1238233adc0d1a8cfa4248783c107158cb356fa95790baab53e08e015e2436f3`。本仓库的评测器快照仍以 v24 为默认口径；此目录是 Prompt 归档，不声称该快照直接支持 `--rubric-profile given_setting_dedup`。
