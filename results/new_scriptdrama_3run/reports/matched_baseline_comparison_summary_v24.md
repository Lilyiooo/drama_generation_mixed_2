# 新版 ScriptDrama 严格配对 Baseline 对比结果（v2.4）

## 实验定义

- 生成模型：Qwen3.6-27B。
- 评测模型：Qwen3.8-27B。
- 评测体系：`drama_evaluator_logic_quality` v2.4，`logic_quality_shared_module_baseline_fusion_multi_agent_6_2_2_2`。
- Candidate：新版 ScriptDrama + Structured State Memory + hybrid 检索 + conservative scene gate。
- Baseline：与同名 Candidate run 使用完全相同的世界观、人设、故事总纲和 60 集分集大纲；第 N 集直接生成剧本，并逐字提供该 baseline 自己此前生成的第 1 至 N-1 集全部原文。
- Baseline 不使用场次大纲 Agent、叙事记忆、状态记忆、hybrid 检索、义务记忆、Strategy 卡、状态门控、桥段检索或生成后改写。
- R01、R02、R03 分别与同名 Candidate 严格配对；每条轨迹 60 集，独立评测一次。
- 本批 Candidate 的世界观字段本来就是空字符串，Baseline 原样复用，未额外补充世界观。

- Candidate 的 run 间稳定性明显更高：逻辑标准差由 5.39 降至 2.45，质量标准差由 6.21 降至 0.80。

## 各 Run 观察

### R01

- 逻辑提升 15.43，质量提升 9.20，是收益最大的一组。
- Baseline 出现角色能力突变、临时规则、身世强行揭示、反派降智和配角工具化等严重问题。
- Candidate 仍存在庞氏权力恢复缺少铺垫、第10至11集重复、龙脉身世口述集中等问题，但严重程度和覆盖范围明显下降。

### R02

- 逻辑提升 12.22，质量提升 8.80。
- Baseline 的九幽寒玉归属、千机毒规则、陆离失忆和软禁时间线存在多项 S 级冲突。
- Candidate 将多数严重冲突降为局部铺垫不足或轻度设定矛盾，逻辑达到三组最高的 85.29。

### R03

- Candidate 逻辑仍提升 4.29，但质量低 0.60。
- Baseline 本身质量达到 87.30，只确认 1 条质量问题和 11 条质量亮点，属于一次异常强的裸模型样本。
- Candidate 质量为 86.70，同样有 11 条亮点，只比 Baseline 多 1 条轻度问题；0.60 的差距很小，不支持“方法稳定损害质量”的结论。
- Candidate 仍在资源、规则时空、伏笔和重复控制上提升，并避免 Baseline 中多项 S/A 级逻辑问题。

## 输出长度

| Run | Baseline 字符数 | Candidate 字符数 | Candidate-Baseline |
|---|---:|---:|---:|
| R01 | 95,046 | 106,563 | +11,517 |
| R02 | 106,987 | 109,773 | +2,786 |
| R03 | 86,323 | 104,250 | +17,927 |

两种方法使用相同的单集目标长度要求，但裸模型更容易主动缩短部分剧集。长度差异是方法实际输出行为的一部分，也可能贡献部分质量差异，解释结果时应同时报告。

## 结论

在严格匹配世界观、人设、故事总纲和分集大纲，并给 baseline 提供其全部历史剧本原文的条件下，Candidate 仍取得：

- 逻辑平均 **+10.65**，3/3 全胜；
- 质量平均 **+5.80**，2/3 胜；
- 所有七个逻辑子维度均值提升；
- 所有五个质量子维度均值提升；
- 更低的 run 间波动；
- 更少的确认问题和更多的确认亮点。

因此，本实验支持：收益不能仅由“看到更多历史正文”解释。结构化状态维护、hybrid 相关状态检索、场次级生成流程与保守门控的组合，在相同规划资产下显著改善了长篇连续剧的逻辑一致性，并在总体上提高剧本质量。

由于只有 3 组配对样本，当前适合报告描述统计、配对胜负和问题类型，不宜宣称统计显著性。后续应在更多不同故事上复现实验，并单独消融 Structured State、hybrid 检索与 gate，以区分各模块贡献。
